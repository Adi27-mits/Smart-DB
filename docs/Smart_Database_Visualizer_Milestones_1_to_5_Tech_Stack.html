2. Milestone-by-Milestone Deep Breakdown

Milestone 1 — Backend Architecture & Connection Infrastructure Foundation

Constructed an enterprise-grade Express REST backend establishing connection pools to MySQL without credential leaks.

Node.js (v24 LTS) Express (4.19.2) mysql2/promise (3.10.1) Zod (3.23.8) Helmet (7.1.0) CORS (2.8.5) express-rate-limit (7.3.1) Nodemon (3.1.4)
  • Connection Pool: createPool with non-blocking async TCP sockets, connection testing, and automatic recovery.
  • Input Validation & Sanitization: Zod schemas validating port ranges, connection payloads, and regex allowlist ([a-zA-Z0-9_]).
  • Security Middleware: Helmet for 11 security headers, CORS origin-locking, and 500 req/15 min IP rate limiting.
Milestone 2 — Schema Introspection & Normalization Engine Introspection

Eliminated hardcoding by introspecting live schema catalogs via parameterized SQL queries and standardizing JSON output.

MySQL INFORMATION_SCHEMA Parameterized SQL REST Controllers TypeScript Models
  • Zero-Config Discovery: Queries TABLES (base tables), COLUMNS (types, nullability, auto-increment), KEY_COLUMN_USAGE (foreign keys), and TABLE_CONSTRAINTS (primary/unique constraints).
  • Normalized Representation: Maps dynamic MySQL metadata into DatabaseSchema (tables array, column lists, relationships array with N:1 cardinality).
Milestone 3 — Interactive Graph Visualization & Auto-Layout Engine Visualization

Engineered an interactive, high-performance canvas rendering tables and relationships with automatic Dagre layout.

Next.js 16 (App Router) React 19 TypeScript 5.7 @xyflow/react (React Flow 12.12) Dagre (0.8.5) Tailwind CSS 4 Lucide React
  • Canvas System: Pan, infinite zoom ($0.15\times - 2.5\times$), mini-map, and custom table cards (TableNode.tsx) with badges (PK, FK, UQ, IDX).
  • Custom Edge Renderer: RelationshipEdge.tsx with SVG cubic bezier curves, target direction arrows, and interactive cardinality chips.
  • Size-Aware Dagre Engine: Injects dynamic table heights ($\text{Height} = 42 + N \times 28\text{px}$) to compute collision-free Left-to-Right (`LR`) and Top-to-Bottom (`TB`) coordinates.
Milestone 4 — Rule-Based Health Inspection Engine & Dependency DAG Health & Diagnostics

Integrated a graph-theoretic health inspection engine executing 5 rules and calculating a project-defined health score.

Graph Algorithms (DAG) STATISTICS Metadata Rule Engine (R001 - R005) Health Score Formulation
  • Rules Implemented: R001 (Missing PK - HIGH), R002 (Orphaned Table - MEDIUM), R003 (Missing FK Candidate - MEDIUM), R004 (Unindexed Foreign Key - LOW), R005 (Circular / Dependency Anomalies).
  • Health Scoring Formula: $\text{Score} = \max\Big(0, \, 100 - (15 \times \text{High} + 8 \times \text{Medium} + 3 \times \text{Low})\Big)$.
  • Structural Dependency Graph: Categorizes tables into root nodes, leaf nodes, and isolated tables with full dependency chains.
Milestone 5 — Table Explorer, Query Console, CRUD & Full Stabilization Integration & Production

Unified all modules with in-depth table exploration, read-only SQL terminal, live CRUD, and 13-point FK pre-validation.

5-Tab Explorer Read-Only SQL AST Parser 13-Point FK Pre-Validator Base UI / Radix Parameterized CRUD Local Visual Filters
  • 5-Tab Table Explorer: Detailed inspection of Overview, Columns, Keys & Constraints, Indexes (from STATISTICS), and Relationships.
  • Read-Only Query Console: AST tokenizer allowing SELECT/SHOW/DESCRIBE/EXPLAIN and read-only WITH; blocks mutations with READ_ONLY_QUERY_CONSOLE and chained SQL with MULTIPLE_STATEMENTS_NOT_ALLOWED. Preserves MySQL error codes (ER_NO_SUCH_TABLE, 42S02).
  • Pre-Validated FK Engine: 13 checks (types, sign, target indexing, orphan records, constraint naming) before running ALTER TABLE.
  • Declared vs. Possible Separation: Confirmed FKs render solid blue; R003 heuristic candidates render dashed amber and never mutate declared schema.
